# 170V Nixie Tube Boost Converter

Designed from scratch in KiCad 8. 

## Features
- 5V Input
- 170V DC Output (for Nixie tubes)
- MC34063 Boost Controller with external MOSFET
- 2-Layer PCB with full ground plane
